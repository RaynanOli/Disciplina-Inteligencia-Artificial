# Disciplina de Inteligência Artificial

Repositório acadêmico destinado ao armazenamento das atividades, exercícios, trabalhos e notebooks desenvolvidos durante a disciplina de **Inteligência Artificial**.

## 📚 Sobre a disciplina

Este repositório reúne os materiais e atividades práticas desenvolvidos ao longo da disciplina, permitindo acompanhar a evolução dos conteúdos e das práticas realizadas durante o semestre.

Os arquivos serão adicionados ao repositório conforme as atividades forem realizadas.

## 📂 Atividades

### Exercícios de Python

**1-Arquivo:** `Exercícios_Python_Raynan_TurmaB_Período6_Noturno.ipynb`

Notebook desenvolvido no Google Colab contendo **50 exercícios de Python**, com atividades que abordam diferentes conceitos da linguagem, desde fundamentos até conteúdos de nível intermediário.

Entre os principais conteúdos trabalhados estão:

* Variáveis e tipos de dados
* Entrada e saída de dados
* Operadores e cálculos
* Estruturas condicionais
* Estruturas de repetição
* Listas
* Dicionários
* Strings
* Funções
* Funções recursivas
* Matrizes
* Algoritmos de busca
* Algoritmos de ordenação
* Módulos e bibliotecas
* Manipulação e análise de dados
* Exercícios práticos e pequenos jogos

O notebook foi desenvolvido e testado utilizando o **Google Colab**, conforme as orientações da atividade.
